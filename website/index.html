01 / REQUEST PROOF

The mechanism is the product.

产品价值来自机制本身。

A request never observes half-applied policy. It enters one active snapshot, crosses route and admission checks, selects an allowed healthy target, then stays on a backpressure-aware stream.

请求不会看到只应用了一半的策略。它进入一个活跃快照，经过路由与准入检查，选择被授权且健康的目标，再沿保持背压的流式通道返回。

02 / WORKLOAD REALITY

Built for the failure modes of AI traffic.

针对 AI 流量的真实故障模式构建。

Long responses, expensive backends, changing model policy, and partial failure are normal conditions—not edge cases.

长响应、昂贵后端、持续变化的模型策略与局部故障是常态，而不是边缘情况。

STREAMING FIDELITY

SSE · WebSocket · gRPC · HTTP/2

Full-duplex bodies, trailers, downstream backpressure, and independent first-response, idle-stream, and total-operation bounds.全双工 body、trailer、下游背压，以及独立的首响应、流空闲与总操作边界。

ATOMIC POLICY

Prove before cutover

切换前完成证明

Invalid middleware, health, listener, or reference policy is rejected before it can replace a live snapshot.无效的中间件、健康检查、监听器或引用策略会在替换活跃快照前被拒绝。

HEALTHY BACKENDS

Fail without amplifying

故障不被进一步放大

Active and passive health, four balancing strategies, circuit state, failover, and pre-response fallback.主动与被动健康检查、四种均衡策略、熔断、故障转移与响应前 fallback。

MANAGED OPENAI

Models · Chat · Completions · Embeddings

Snapshot-local authentication, model grants, RPM/burst/concurrency admission, model rewriting, request identities, and ordered healthy targets.快照内鉴权、模型授权、RPM/burst/并发准入、模型重写、请求身份与有序健康目标。

03 / SYSTEM BOUNDARY

Control in Cloud. Traffic in Gateway.

控制在 Cloud，流量在 Gateway。

A3S Cloud owns human operations, placement, production rollout, managed replicas, and the long-term usage ledger. Gateway owns protocol handling and local enforcement. Standalone ACL and complete Cloud snapshots enter the same fail-closed runtime preparation boundary.

A3S Cloud 负责人工运维、放置、生产发布、受管副本和长期用量账本；Gateway 负责协议处理与本地执行。独立 ACL 与完整 Cloud 快照进入同一个 fail-closed 运行时准备边界。

04 / FIRST SUCCESS

One command to the first request.

一条命令，走到第一个请求。

The native installers detect the platform, require the published SHA-256 checksum, verify the binary version, and replace only the user-local binary. Run standalone, in Docker or Helm, behind A3S Cloud, or as a Rust library.

原生安装器会检测平台、强制校验发布的 SHA-256、验证二进制版本，并且只替换用户目录中的二进制。随后可独立运行、通过 Docker/Helm 部署、接收 A3S Cloud 快照，或作为 Rust 库嵌入。

05 / SEPARATE PROCESS SURFACE

Agent utilities stay outside the traffic hot path.

Agent 工具位于流量热路径之外。

Gateway can discover standard SKILL.md packages and start native coding-agent CLIs with exact argument passthrough. It does not replace those agents, own their sessions, or mix process control into request routing.

Gateway 可以发现标准 SKILL.md 包，并以精确参数透传启动原生 coding-agent CLI。它不会替代这些 Agent、接管会话，也不会把进程控制混入请求路由。
