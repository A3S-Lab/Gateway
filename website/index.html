02 / SYSTEM MAP

One binary. Two explicit planes.

一个二进制，两条明确边界。

Agent processes stay outside the proxy hot path. Traffic stays on one validated local snapshot. Neither path needs a synchronous Cloud round trip.

Agent 进程位于代理热路径之外，流量始终运行在一个已验证的本地快照上；两条路径都不需要同步访问 Cloud。

03 / TRAFFIC

Long-lived AI traffic, treated as a first-class workload.

把长连接 AI 流量当作一等工作负载。

Gateway validates complete policy before cutover, preserves backpressure, and stops fallback as soon as an upstream response starts.

Gateway 在切换前验证完整策略，保持背压，并在上游响应开始后立即停止 fallback。

STREAMING

SSE, WebSocket, gRPC

Independent first-response, idle-stream, and total-operation limits.独立的首响应、流空闲与总操作超时。

SNAPSHOT

Atomic policy

原子策略

A rejected reload leaves the prior proven snapshot active.被拒绝的 reload 不会替换已验证快照。

ROUTING

Healthy targets

健康目标

Local health suppresses endpoints but never invents them.本地健康检查只抑制端点，绝不凭空创建端点。

MANAGED OPENAI

Models · Chat · Completions · Embeddings

Snapshot-local auth, model grants, request limits, rewriting, and pre-response fallback.快照内鉴权、模型授权、请求限制、重写与响应前 fallback。
